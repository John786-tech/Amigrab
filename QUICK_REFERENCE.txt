┌─────────────────────────────────────────────────────────────────────────────┐
│ 🚀 QUICK START                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

1. Create .env file:
   FLASK_ENV=development
   SECRET_KEY=your-secret-key
   SENDER_EMAIL=your-gmail@gmail.com
   SENDER_PASSWORD=your-app-password

2. Install dependencies:
   pip install -r requirements.txt

3. Run application:
   python app_new.py

4. Open browser:
   http://localhost:5000
